## 📌 About the Project

**AlgoQuest** is an interactive graphical desktop application developed using the C programming language and Raylib graphics library.

The project demonstrates the practical implementation of fundamental Data Structures through an interactive graphical interface.

Users can perform different operations on data structures and observe how elements, pointers, and memory relationships change during execution.

The main objective is to make Data Structures easier to understand by combining programming logic, graphical visualization, and practical interaction.

## ⚙️ Installation and Setup

### Requirements

- Windows 10/11
- Visual Studio Code
- MSYS2
- GCC compiler
- Raylib graphics library

### 1. Clone the Repository

```bash
git clone https://github.com/sujeettechwork-creator/AlgoQuest-Interactive-Data-Structures-Algorithm-Visualizer.git
```

### 2. Open the Project

```bash
cd AlgoQuest-Interactive-Data-Structures-Algorithm-Visualizer
```

Open the folder in Visual Studio Code.

### 3. Verify GCC Installation

```bash
gcc --version
```

### 4. Verify Raylib Installation

Ensure Raylib is installed and configured in the MSYS2 UCRT64 environment.

### 5. Build and Run

Use the configured VS Code build task after verifying the source and header include paths.

The application can be launched using the generated executable:

```bash
./AlgoQuest.exe
```
